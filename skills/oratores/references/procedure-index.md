# Procedure Index

89 stable procedure IDs. Use them in briefs, plans, review findings and post-mortems. Each ID has one canonical home; installed source packs are evidence, not duplicate procedures.

`Required output` is routing shorthand. Where the module body also states it, **the body wins**. A missing Gates or Failure Signals section is not a claim that no gates apply.

This file is a routing index. It is never a user-facing artifact, and answering a task from a row here instead of opening the module it names is a routing failure — the row states what to produce, the module states the controls that make it correct.
